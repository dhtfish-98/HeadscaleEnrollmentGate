# Origin and rights

The implementation in `src/headscale_enrollment_gate` and `lab/` was written for this project by **dhtfish98**. It is an independent operator-side control that calls Headscale's documented CLI; it is not a fork, patch or port of Headscale's registration code. It does not claim to fix a known Headscale defect.

The fixed upstream reference is `juanfont/headscale` commit [`eeaac680bef26585c8cc1569f949e26d0d6aba80`](https://github.com/juanfont/headscale/commit/eeaac680bef26585c8cc1569f949e26d0d6aba80) (2026-09-30 UTC). The examined surfaces are [`hscontrol/auth.go`](https://github.com/juanfont/headscale/blob/eeaac680bef26585c8cc1569f949e26d0d6aba80/hscontrol/auth.go), [`hscontrol/db/preauth_keys.go`](https://github.com/juanfont/headscale/blob/eeaac680bef26585c8cc1569f949e26d0d6aba80/hscontrol/db/preauth_keys.go) and [`hscontrol/types/preauth_key.go`](https://github.com/juanfont/headscale/blob/eeaac680bef26585c8cc1569f949e26d0d6aba80/hscontrol/types/preauth_key.go). Those sources already validate used and expired keys, assign user or tag scope, and persist key use. The [official registration guide](https://headscale.net/development/ref/registration/) likewise describes a default one-use, one-hour key. The separate gate adds an operator approval, a one-redemption grant and a durable policy check before such a key is issued.

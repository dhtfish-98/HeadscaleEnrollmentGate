# Boundary and limits

The protected operation is **issuing a Headscale pre-authentication key** from a trusted management host. The relevant mistakes are issuing for the wrong user, broadening a tag set, granting an excessive lifetime, repeating a grant or issuing after approval has expired or been revoked. The gate records an exact scope in SQLite, rechecks the current policy at redemption, requests a non-reusable Headscale key, validates returned user/tags/expiry metadata, and closes the grant before making the external request. A second redemption cannot mint another key, including after process restart.

The Headscale control socket is outside the gate. A caller with direct access to that socket can issue keys without the gate, so deployment must restrict it to the trusted service account. The policy file and SQLite directory also belong to that account. The `audience` field is an operator-side policy selector, not proof of a remote human identity.

After the key is returned, it is a bearer secret. A person who obtains it before the intended client uses it may register another node; this gate cannot cryptographically bind it to a hardware device. User-owned keys and tagged keys have different Headscale ownership semantics. For tagged keys, the optional user ID records the issuer while the resulting node belongs to Headscale's tagged-device identity. A client's attempt to change the grant's user or tags is rejected before issuance, while Headscale performs the authoritative registration checks.

The durable `issuing` state is intentionally not retried after a crash. If Headscale created a key just before a process failure, an unused orphan key may exist in Headscale's database; the secret is never delivered or stored by the gate. An operator should inspect and expire that key through Headscale. The gate compares observed wall-clock values and closes on a rollback, but expiration still depends on a trustworthy host clock. The local experiment proves only the documented synthetic cases, not resistance to a compromised management host or a stolen bearer key.
